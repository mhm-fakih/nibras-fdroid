# Nibras PIM — F-Droid repository

An F-Droid-compatible repository for the apps of [Nibras PIM](https://github.com/mhm-fakih/nibras-pim)
(free software, AGPL-3.0). Currently: **knotes**, the Android app.

## Add it to your F-Droid client

In F-Droid, Droid-ify, Neo Store or any compatible client: **Settings → Repositories → +**, then enter

```
https://mhm-fakih.github.io/nibras-fdroid/repo
```

The index is signed. To check you have the genuine repository, its key fingerprint (SHA-256) is:

```
4E6533C6F4783BD04CF7A9278CF5963A5E7DE77D486EA32FBD3AA4E5CCEDC2F3
```

or open this link on the phone, which adds the repository with the fingerprint pinned:
https://mhm-fakih.github.io/nibras-fdroid/repo?fingerprint=4E6533C6F4783BD04CF7A9278CF5963A5E7DE77D486EA32FBD3AA4E5CCEDC2F3

The APKs here are the same files attached to the project's
[GitHub releases](https://github.com/mhm-fakih/nibras-pim/releases), signed by the author.
